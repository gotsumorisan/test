1) パチスロ戦国乙女 暁の関ヶ原-DARKNESS-
   - Store: オーロラ北見店
   - CZ ceiling: 634G -> CZ「戦国モード」. AT is not guaranteed by this ceiling.
   - AT ceiling: 969G + premonition -> AT「乙女ラッシュ」.

2) パチスロ バイオハザード7 レジデント イービル
   - Store: オーロラ北見店
   - Mode ceilings: Normal A 753G / B 603G / C 503G / Heaven 153G+α -> CZ「クライマックスバトル」.
   - Game ceiling guarantees CZ only, not AT, so direct payout guarantee at ceiling is 0 medals.
   - CZ is a two-stage battle: 1st 15G, 2nd 7G. Both must be cleared for AT.
   - AT「ハザードラッシュ」 is a game-add-on AT with pure increase about 5.0 medals/G; initial games are decided by an entry feature.
   - Sources: https://nana-press.com/kaiseki/machine/105/2580/ ; https://nana-press.com/kaiseki/machine/105/2478/ ; https://nana-press.com/kaiseki/machine/105/2479/

3) ボンバーガール
   - Store: オーロラ北見店
   - Chance-interval ceiling: 460G+α from CZ / bonus / AT -> AT「ボンバータイム」.
   - Bonus-interval ceiling: 960G+α from bonus / AT -> AT「ボンバータイム」.
   - The two counters have different reset triggers and must not be merged.
   - AT is 100G+α per set; pure increase about 0.7 medals/G, or about 2.5 medals/G during Rush Time. No fixed minimum medal payout is created from these values.
   - Sources: https://nana-press.com/kaiseki/machine/408/10951/ ; https://nana-press.com/kaiseki/machine/408/11082/

4) 新世紀エヴァンゲリオン ～魂の共鳴～
   - Store: オーロラ北見店
   - Game-count ceilings: 222 / 333 / 666G, with 700G as premium ceiling -> bonus (AT). Basic maximum is 666G.
   - CZ「ゼルエル決戦」 max 5 misses -> next bonus (AT).
   - AT first hit can be 暴走ボーナス (30G, pure increase about 3.4 medals/G) or 覚醒ボーナス (initial 100 medals + two Longinus Spear add-on guarantees, expected about 560 medals including the bonus).
   - The ~560 medals is an expected/average figure, not a ceiling minimum guarantee.
   - Sources: https://nana-press.com/kaiseki/machine/285/7573/ ; https://nana-press.com/kaiseki/machine/285/7581/ ; https://nana-press.com/kaiseki/machine/285/7582/
