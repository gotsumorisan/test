1. Beginner-friendly exchange wording
Problem:
The source-style labels "等価" and "5.6枚" are accurate but too technical for a beginner.

UI-only rendering change:
- 等価 / 等価交換 -> 交換ロスなし
- 5.6枚 -> 56枚=1000円交換
- 5.6枚現金 -> 56枚=1000円交換・現金投資
- Numeric lines now render with a separator, e.g.
  source DB: 等価650G～ / 5.6枚750G～
  screen:    交換ロスなし：650G～ / 56枚=1000円交換：750G～

A short glossary was added to the normal-rate section:
- 交換ロスなし = lending and exchange medal value are the same
- 56枚=1000円交換 = 56 medals are required for 1000 yen of prize value
- If the exchange rate is unknown, do not guess; confirm in chat.

The underlying strategy DB keeps source terminology so source comparisons remain traceable; beginner wording is applied only at render time.
