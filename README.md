# HALL SCAN v3.15

2026-09-20 仕上げ版。iPhone 17で店内巡回中に片手で素早く確認する用途を最優先。

- 網走4店舗 + 北見10店舗
- 14店舗横断の機種検索 / お気に入り
- 統合店舗ディレクトリ
- 画像ガイド（画像優先の高速照合レイアウト）
- iPhone safe area / viewport-fit=cover / 100dvh 対応
- iframe不使用
- PWA / オフラインHTML / runtime画像キャッシュ

GitHub Pagesでは、このフォルダの中身をリポジトリ直下に配置してください。
